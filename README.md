## Reinessance HL2RP - Український MRP проєкт на основі ігрового режиму DarkRP

Проєкт визнаний закритим через велику кількість багів та помилок, які не фіксились та не піддавались перевірці. Даний репозиторій містить в собі модулі до сервера, які використовувались під час його існування.

УВАГА: УВЕСЬ КОД (або більша його частина) НАПИСАНА ШТУЧНИМ ІНТЕЛЕКТОМ. Прошу брати це до уваги в разі завантаження репозиторію.
